# Unit Converter

A feature-rich Python command-line unit conversion utility with an interactive menu system and a wide collection of conversions across multiple measurement categories.

## Features

* Interactive menu-driven interface
* 15 conversion categories
* Length conversion
* Area conversion
* Volume conversion
* Weight and mass conversion
* Temperature conversion
* Time conversion
* Speed conversion
* Pressure conversion
* Energy conversion
* Power conversion
* Data storage conversion
* Frequency conversion
* Angle conversion
* Fuel economy conversion
* Digital and computing unit conversion
* Input validation for numeric values
* Reusable conversion functions
* Easy-to-navigate category and conversion menus

## Conversion Categories

| Category            | Examples                                                       |
| ------------------- | -------------------------------------------------------------- |
| Length              | Kilometers, Miles, Meters, Feet, Inches, Yards, Nautical Miles |
| Area                | Square Meters, Square Feet, Square Miles, Acres, Hectares      |
| Volume              | Liters, Gallons, Milliliters, Cubic Meters, Pints, Quarts      |
| Weight / Mass       | Kilograms, Pounds, Grams, Ounces, Tonnes                       |
| Temperature         | Celsius, Fahrenheit, Kelvin                                    |
| Time                | Seconds, Minutes, Hours, Days                                  |
| Speed               | km/h, mph, m/s, Knots                                          |
| Pressure            | Pascal, Bar, PSI, Atmosphere                                   |
| Energy              | Joules, Kilojoules, Calories, Kilocalories, BTU                |
| Power               | Watts, Kilowatts, Horsepower, Megawatts                        |
| Data Storage        | Bits, Bytes, KB, MB, GB, TB                                    |
| Frequency           | Hertz, Kilohertz, Megahertz, Gigahertz                         |
| Angle               | Degrees, Radians, Gradians                                     |
| Fuel Economy        | MPG, L/100 km, km/L                                            |
| Digital / Computing | Bits, Bytes, Data Transfer Units                               |

## Requirements

* Python 3.x
* No external libraries required

## Installation

Clone the repository:

```bash
git clone https://github.com/R3L1C5/Unit-Converter.git
```

Navigate to the project directory:

```bash
cd Unit-Converter
```

## Run

```bash
python3 unit_converter.py
```

## Usage

Launch the program and select a conversion category from the main menu.

```text
UNIT CONVERTER v2.0

1. Length
2. Area
3. Volume
4. Weight / Mass
5. Temperature
6. Time
7. Speed
8. Pressure
9. Energy
10. Power
11. Data Storage
12. Frequency
13. Angle
14. Fuel Economy
15. Digital / Computing Units
0. Exit
```

Select a category, choose the required conversion, enter the value, and the converted result will be displayed.
